# Security Notes

My personal cybersecurity knowledge base — organized, searchable notes on
offensive security topics. Built as I learn, used as a quick reference during
CTFs, labs, and bug bounty engagements.

Inspired by references like [HackTricks](https://book.hacktricks.xyz) and
[PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings),
this is my own growing library.

## Purpose
- Turn scattered notes into a structured, searchable reference
- Fast lookup during engagements (Ctrl+F beats memory)
- Track my learning progress over time
